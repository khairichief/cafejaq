# cafejaq

Website for Cozy Cafe, Cadillac, MI. Plain HTML, CSS and JavaScript — open `index.html` in a browser, no build step.

- `index.html`, `about.html`, `menu.html`, `contact.html` — pages
- `js/main.js` — menu items and prices (edit the `MENU` object), plus page scripts
- `css/style.css` — styles and brand colours
